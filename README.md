# Critical Fail Shared

Critical Fail Shared is Foundry VTT Module for The Critical Fail Server D&amp;D games. Inside the module contains various compedium packs for use for games run in the Azure Realms campaign setting. Games run with this module assume the PF1 Game System.

The Spheres of Guile Talents pack contains the skill spheres from Artifice through Vocation. Each entry is a Pathfinder feat with the skill talent type used by the Spheres module (`pf1spheres`). Sphere rules text is Open Game Content compiled from the [Spheres of Power Wiki](https://spheresofpower.wikidot.com/start).

Rebuild that pack with `node tools/build-guile-talents.mjs` after installing Foundry's `classic-level` dependency (the script loads it from `F:\Code\Foundry Code`).
